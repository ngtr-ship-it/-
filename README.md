# 📓 タスク帳

ブラウザで動くシンプルなタスク管理帳です。`index.html` をブラウザで開くだけで使えます（インストール不要）。

## 機能
- タスクの追加・編集・削除・完了チェック
- 期限（期限切れ・今日の期限を強調表示）、優先度（高・中・低）、カテゴリ、メモ
- 絞り込み：すべて／未完了／今日／期限切れ／完了
- キーワード検索、カテゴリ絞り込み、並び替え（期限・優先度・追加順）
- 完了済みタスクの一括削除
- JSON で書き出し・読み込み（バックアップや端末間の移行に）
- ライト／ダークテーマ（自動切り替えあり）、スマホ対応

## データの保存先
タスクはブラウザの localStorage に保存されます。ブラウザのデータを消すとタスクも消えるので、大事なタスクは「書き出し（JSON）」でバックアップしてください。
