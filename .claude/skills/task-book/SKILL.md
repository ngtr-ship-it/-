# タスク帳

- 場所：https://claude.ai/artifact/1YsRzMYKwHfgEN5Am8DZdk
- タスクはアーティファクトのデータベースの `tasks` コレクションに入っている
- 1件の形：`{ title: 文字列, done: true/false, createdAt: ミリ秒, doneAt: ミリ秒 または null, dueDate: "YYYY-MM-DD" または null, order: 数値 }`
  - `order` が小さいほど上に並ぶ。新しく足すときは、今ある「やること」の一番大きい order に 1000 を足した値にする
  - 期日は「…」メニューからあとで変えたり消したりできる
- 「タスク帳に〇〇を追加して」と頼まれたら、ArtifactData で `tasks` に書きこむ

## 決まりごと

- おわったタスクは、おわったその日のうちだけ残す。日付が変わったら消す（見ている人の端末の時刻で判定）
  - ページを開いたときに、きのう以前におわったものを自動で消すようにしてある
- 表示の切りかえは「やること」と「おわった」の2つだけ。「ぜんぶ」はいらない
- 「やること」はドラッグ（⋮⋮ のつまみ）か、つまみを選んで上下の矢印キーで並べかえられる
- 期日がきょうのものはオレンジ、すぎたものは赤で目立たせる
- 書きこめるのはオーナー（バディ~）だけ
