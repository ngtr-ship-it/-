# タスク帳

- 場所：https://claude.ai/artifact/1YsRzMYKwHfgEN5Am8DZdk
- タスクはアーティファクトのデータベースの `tasks` コレクションに入っている
- 1件の形：`{ title: 文字列, done: true/false, createdAt: ミリ秒, doneAt: ミリ秒 または null }`
- 「タスク帳に〇〇を追加して」と頼まれたら、ArtifactData で `tasks` に書きこむ

## 決まりごと

- おわったタスクは、おわってから1日（24時間）だけ残す。すぎたら消す
  - ページを開いたときに、期限がすぎたものを自動で消すようにしてある
- 表示の切りかえは「やること」と「おわった」の2つだけ。「ぜんぶ」はいらない
- 書きこめるのはオーナー（バディ~）だけ
